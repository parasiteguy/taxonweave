# TaxonWeave manuscript examples

This directory contains the input files (specifically for the batch query) and TaxonWeave outputs used for
the example applications presented in the TaxonWeave manuscript.

The examples demonstrate single-taxon and batch workflows under different
nomenclatural scenarios, including accepted names, synonym-aware retrieval,
and resolution of an unaccepted taxonomic name to its currently accepted
WoRMS concept.

## Software version

The analyses were performed using TaxonWeave v0.2.1.

TaxonWeave is available from PyPI:

    pip install TaxonWeave

Source code and development history are available in the main TaxonWeave
repository.


## Single-taxon example

The single-taxon example uses *Polydora websteri* as a baseline case in
which the queried name is currently accepted by WoRMS and no nomenclatural
synonyms are returned.

The analysis can be reproduced with:

    taxonweave query "Polydora websteri" --export --output Polydora_websteri

The exported files contain the resolved taxonomy, synonym information,
GenBank search results, sequence-level records, reconciliation results,
molecular metadata, and summary statistics used in the manuscript.

## Batch example

The batch analysis uses three marine annelid taxa representing different
nomenclatural scenarios:

- *Polydora websteri* — accepted name with no WoRMS synonyms
- *Ficopomatus enigmaticus* — accepted name with multiple WoRMS synonyms
- *Polydora neocaeca* — unaccepted name currently treated by WoRMS as a
  junior subjective synonym of *Polydora caeca*

The input file `input_species.csv` contains:

    scientific_name
    Polydora websteri
    Ficopomatus enigmaticus
    Polydora neocaeca

The batch analysis can be reproduced with:

    taxonweave batch polychaete_species.csv --output batch_query

TaxonWeave resolves *Polydora neocaeca* to the accepted *Polydora caeca*
concept. The corresponding output directory is therefore named
`Polydora_caeca`.

## Output files

Taxon-level directories contain the CSV files generated by TaxonWeave,
including:

- `summary.csv` — summary of the taxonomic and molecular reconciliation
- `taxonomy.csv` — WoRMS taxonomic classification
- `synonyms.csv` — nomenclatural synonyms returned by WoRMS
- `genbank_searches.csv` — GenBank searches performed across taxonomic names
- `sequences.csv` — sequence-level provenance, reconciliation, and molecular
  metadata

The batch workflow additionally produces `batch_summary.csv`, which
summarizes results across all submitted taxa.

## Reproducibility

WoRMS and GenBank are dynamic databases. These example outputs represent
the state of the underlying resources when the analyses were performed.
Re-running the same commands at a later date may therefore produce
different taxonomic relationships, record counts, or metadata as WoRMS
and GenBank are updated.
