# TaxonWeave

TaxonWeave is a Python framework for provenance-aware reconciliation of
taxonomic concepts and molecular sequence records.

TaxonWeave currently integrates taxonomic information from the World
Register of Marine Species (WoRMS) with nucleotide records from GenBank.

The framework preserves the distinction between:

- the taxonomic name used to retrieve a molecular record;
- the taxonomic name under which that record was deposited;
- the currently accepted taxonomic concept;
- molecular and specimen-associated evidence attached to the record.
